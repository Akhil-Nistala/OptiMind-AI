# Data provenance

Production records and local text procedures are synthetic authored demonstration fixtures. They are not DENSO, Yamaha or other factory records. Public PDF tip sheets are attributed in documents/public_sources.json; exact downloaded hashes are copied into results/document_provenance.json. Model revisions and hashes are in results/model_provenance.json. Cached indexes and SQLite files are regenerated by scripts.prepare_data and index commands. No credentials are needed for the public local models.
